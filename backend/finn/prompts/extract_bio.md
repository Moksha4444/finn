This is a management-change disclosure filed by an Indian listed company. List every person whose role changes, one entry per person.

Rules:
- Use only this filing. No outside knowledge, even if you recognise the person.
- `change`: appointed, re-appointed, redesignated, resigned, retired or ceased.
- `role`: the role as the filing states it, short (e.g. "MD & CEO", "Independent Director", "Chairman"). If one person gets several roles, put them all in this one entry (e.g. "CEO Designate; CEO & MD from May 1, 2027"). `change` is the main change (a retirement with an honorary title is "retired").
- `effective`: the effective date as printed, or null.
- `bio`: only if this filing contains a profile of the person. At most 35 words, condensed from the profile in this order: current role, notable previous roles, years of experience, education. Keep the filing's tense ("has been a partner at" must not become "is a partner at"). No praise, no adjectives the filing doesn't use. null if there is no profile in this filing.
- `bio_page`: the page number of the profile within this PDF (first page = 1), or null.
- `profile_ref`: if the filing says the profile was disclosed earlier, the reference as printed (e.g. "intimation dated October 1, 2026"); otherwise null.
- Ignore people only listed as contacts or signatories.
